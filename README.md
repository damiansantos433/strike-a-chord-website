# Strike a Chord

A responsive multi-page website for a fictional local music store specializing in instrument lessons, rentals, and music education.

## Live Demo

http://cis190a.nupurple.net/dsantos/Music/index.html

## Features

- Multi-page website with clear navigation
- Information about instrument lessons and rental services
- Instructor profiles and contact page
- Embedded promotional video
- Clean and user-friendly layout

## Technologies Used

- HTML
- CSS

## What I Learned

- Building multi-page websites with consistent layouts
- Embedding media such as images and video
- Designing service-focused web pages
- Applying responsive design principles

## How to Run Locally

1. Clone or download the repository
2. Open `index.html` in your browser

## Notes

This project highlights my ability to design and structure a multi-page website with a focus on clean layout, organized content, and user-friendly navigation.
